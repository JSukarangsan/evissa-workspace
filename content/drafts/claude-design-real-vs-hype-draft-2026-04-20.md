Spent time with Claude Design this week. Separating signal from noise.

What actually works:

👉 Brand kit generation from an existing codebase. You connect a repo, Claude reads it, and produces a SKILL.md encoding your colors, typography, spacing, and design rules. The fidelity is better than screenshot-based alternatives. This is genuinely new.

👉 Prototype quality. A developer linked a Laravel codebase and Claude produced 26 preview cards, two full UI kits, and a unified CSS token file reconciling two separate stylesheets. Reviewers called it "not template work."

👉 Export flexibility. HTML, PDF, PPTX with editable text (rare), or a handoff bundle that drops straight into Claude Code for production implementation. The Canva integration is solid for decks and one-pagers.

What doesn't work:

A Pro subscription gets you roughly 30 minutes of use before you're locked out for the week. PCWorld confirmed this. A Max 5x tester burned 90% of their Claude Design allowance in four or five prompts.

Collaboration is barely there. Inline comments sometimes disappear before Claude reads them. Compact view triggers save errors. Connecting large monorepos causes browser lag. Enterprise plan ships with the feature off by default.

The power user workaround is already obvious. Generate your brand kit SKILL.md in Claude Design, then drop it into Claude Code and continue iterating on Code's separate token meter. Tbh the fact that the best move is to leave the product as fast as possible tells you where the pricing model is.

🎯 Who should actually use this right now

Founders and PMs who need pitch decks, landing pages, or interactive prototypes and don't have a designer on call. The brand-kit-from-codebase pipeline is the killer feature for teams already in the Claude Code ecosystem.

Designers with established workflows and team collaboration needs? Not yet. Maybe not ever, depending on how Figma responds.

The tool is real. The pricing isn't ready. Plan accordingly.
