## 💡 SPARK

OpenAI built Symphony internally to solve their own agent coordination problem, saw 500% more PRs, and then open-sourced it. That's the same pattern as every major infrastructure project: build it because you need it, open-source it because the ecosystem makes it better. The interesting question isn't "what does Symphony do" — it's "why is the issue tracker the right control plane?" The answer: because that's where intent already lives. Tasks in Linear have context, priority, acceptance criteria. Agents don't need a new interface — they need access to the same interface humans already use. That's context engineering at the organizational level. Jon's been saying "context is the new infrastructure" — Symphony is the first major open-source project that treats it that way.
