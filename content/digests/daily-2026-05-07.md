# Daily Briefing — Thursday, May 7, 2026

## THEME

AI is graduating from individual productivity tool to organizational infrastructure. The evidence lands all at once today: coding agents writing 60% of a fintech's PRs, 1 million Notion agents created in 2 months, Cursor shipping an SDK to embed agents into CI/CD pipelines. The question has shifted from "should we?" to "how do we run this at scale?" — which is exactly the AI ops question nobody in the market is answering well yet.

## 📰 UPDATES

Usage-based pricing now live.

- **[Build Programmatic Agents with the Cursor SDK](https://www.cursor.com/blog/typescript-sdk)** (Cursor) — Cursor's coding agents are now available as programmable infrastructure. Teams are embedding them directly into CI/CD pipelines and products. Coding agents are evolving from dev tools for individuals to infrastructure for organizations. Published Apr 29.
