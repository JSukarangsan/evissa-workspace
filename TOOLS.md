# Tools                                                                                                 
                                                                                                          
  ## File System                                                                                          
                                              
  The content pipeline lives in the workspace. Key directories:                                           
  - content/ideas/backlog/ - Raw captured ideas                                                           
  - content/ideas/ready/ - Ideas ready for drafting                                                       
  - content/ideas/archive/ - Stale or used ideas                                                          
  - content/drafts/ - Work in progress (organized by week folders)                                        
  - content/published/ - Archive of published content                                                     
  - content/plans/ - Content plans
  - content/digests/ - Daily digest archives                                                              
                                                                                                        
  ## Core Context
                                                                                                          
  Always at context/ in the workspace root:   
  - context/brand-voice.md - MUST READ before writing any content                                         
  - context/services.md - Service offerings and value props                                             
  - context/strategy.md - Current strategic priorities (updated monthly/quarterly)                        
                                              
  ## External Services                                                                                    
                                                                                                          
  - Notion: Reading list database for content inspiration                                                 
  - Typefully: X/Twitter post scheduling                                                                  
  - Kit: Newsletter publishing (template ID 4883052)                                                                                                                     
                                              
  ## Slack Channels                       

  - #briefings - Daily digest output                                                                      
  - #ideas - Idea capture input
  - #drafts-review - Content approval workflow                                                            
  - #published - Publication confirmations
